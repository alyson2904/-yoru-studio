Caso de Estudio

Instituto Educativo José María Morelos

Un proyecto de desarrollo web integral para una institución educativa con múltiples niveles académicos. El objetivo principal fue digitalizar su oferta educativa, facilitar el acceso a la información y optimizar la captación de nuevos estudiantes a través de canales directos.

El Desafío

La institución contaba con una gran cantidad de información académica (desde nivel preescolar hasta maestrías), pero no tenía una plataforma centralizada y moderna que la presentara de manera clara. Además, el proceso para solicitar informes o contactar a la escuela era lento y poco intuitivo para los padres de familia y futuros alumnos.

El reto consistía en organizar toda esa estructura académica en un sitio web rápido, visualmente atractivo y fácil de navegar desde cualquier dispositivo móvil.

La Solución Construida

Desarrollé un sitio web a medida utilizando HTML, CSS y JavaScript, enfocado en una arquitectura de información limpia. Se diseñaron secciones específicas para cada nivel educativo, permitiendo a los usuarios explorar los programas académicos de forma detallada.

Se integraron elementos interactivos clave, como ventanas modales para visualizar las mallas curriculares sin tener que salir de la página, y mapas interactivos para ubicar las instalaciones. Todo el flujo de contacto se redirigió a WhatsApp para agilizar la atención al cliente.

Características Técnicas

  • Diseño 100% responsivo para móviles y PC.
  • Estructura semántica y optimizada para SEO.
  • Ventanas modales dinámicas para mallas curriculares.
  • Integración directa de botones de contacto a WhatsApp.
  • Mapa de ubicación interactivo de Google Maps.
  • Optimización de tiempos de carga y recursos visuales.
