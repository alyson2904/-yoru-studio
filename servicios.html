Lo que puedo ofrecer

Servicios del estudio

01 — WEB DESIGN

Diseño web

Páginas con una estructura clara y una identidad visual coherente con tu proyecto.

  • Diseño adaptable a celular y computadora
  • Jerarquía visual y navegación
  • Diseño de landing pages
  • Integración de enlaces de contacto
02 — BRAND IDENTITY

Identidad visual

Un sistema gráfico que ayuda a comunicar la personalidad de una marca.

  • Dirección visual
  • Paleta de color y tipografía
  • Recursos gráficos
  • Consistencia entre piezas
03 — DIGITAL DESIGN

Diseño para redes

Piezas visuales pensadas para comunicar mensajes con orden y personalidad.

  • Diseño de publicaciones
  • Portadas y recursos gráficos
  • Plantillas visuales
  • Adaptación de formatos
04 — CREATIVE DIRECTION

Dirección creativa

Una línea visual definida para que las distintas piezas de un proyecto tengan coherencia.

  • Referencias e inspiración
  • Concepto visual
  • Composición y estilo
  • Guía de consistencia visual
Los alcances, tiempos y precios se definen de acuerdo con las necesidades de cada proyecto. La disponibilidad de cada servicio debe confirmarse al contactar al estudio.
